# BEAST heating COP curves

Generated by calling `heatingOperatingPoint()` from the existing `lib/rtu-curves.ts`, including its bundled performance maps. No performance equations are duplicated in the plotting script.

- One 25-ton unit; full-load heating operation.
- Coil-entering air held at 70°F and 50% RH, rather than varying with building return/outdoor mixing.
- Outdoor temperature swept from −15°F to 65°F in 0.25°F steps; outdoor RH held at 50%.
- Default supply airflow of 404 CFM/ton and default heating lockout of 0°F.
- Below lockout, COP is undefined, not zero. Dashed curves identify clamped map inputs.
- COP includes mapped compressor/outdoor-fan input and excludes supply-fan power, reheat, and cycling losses. No extra defrost adjustment is applied.
- The cold-climate family is a hypothetical specification, not a product; its stage changes near 17°F.

Regenerate data with `node scripts/export-cop-curve.mjs`, then render with `python scripts/plot-cop-curve.py` (requires Matplotlib; also detects an installation under the ignored `.sites-runtime/pythonplot` directory).

The CSV and JSON retain capacity, electrical input, COP, lockout, and map-boundary status. The export checks that every operating point's COP equals heating capacity divided by electrical input in consistent units. PNG is for preview; SVG and PDF are vector exports.
